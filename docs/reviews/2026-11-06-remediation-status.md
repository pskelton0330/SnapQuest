## Limits of verification

The automated suite exercises migration contracts and app logic, but this environment has no connected mobile browser session. The requested 320/375/390 px, 200% zoom, screen-reader, iOS native-share, and two-physical-device walkthroughs have not been directly observed. Treat R19 as implemented pending that visual/accessibility walkthrough. Production RLS and Storage policy definitions remain read-only inspected; actual Storage HTTP denial/allowance cases and simultaneous PostgreSQL review/finalization races still require isolated hosted acceptance. Migration 026 is live, but its real Storage HTTP behavior still needs isolated hosted verification. Migration 027’s ACL and basic anon PostgREST allow/deny behavior are verified in production; the broader authenticated/member/non-member role matrix remains under IMP-05/15.
